# DelfinDiscordPython

Delfin's official bot (python) discord.

## Features

1. Ai discord bot using /ask with Groq api

## Installation

1. Install python, from anywhere you want

2. Install all library

3. Copy .env.example to .env and change all environtments variabel

```bash
pip install -r requirements.txt
```

## Run

```bash
python main.py
```
